# ClassApex Mobile Build Setup

This document explains how to build the ClassApex LMS frontend as native iOS and Android apps using [Capacitor](https://capacitorjs.com/).

## Prerequisites

- Node.js >= 22.0.0 (Capacitor CLI requirement)
- pnpm
- For iOS: macOS with Xcode installed
- For Android: Android Studio with SDK and Gradle

## Installed Capacitor Dependencies

The following packages have been added to the app:

- `@capacitor/core`
- `@capacitor/cli`
- `@capacitor/ios`
- `@capacitor/android`
- `@capacitor/splash-screen`
- `@capacitor/status-bar`

## Project Structure

```
canvas-modern-ui/apps/classapex-lms/
├── capacitor.config.ts    # Capacitor configuration
├── ios/                   # Native iOS project (generated)
├── android/               # Native Android project (generated)
└── dist/                  # Web build output used as webDir
```

## Configuration

`capacitor.config.ts` is configured with:

- **appId**: `com.classapex.lms`
- **appName**: `ClassApex`
- **webDir**: `dist` (Vite build output)
- **androidScheme**: `https`
- **SplashScreen** and **StatusBar** plugin settings matching the app theme

## Build Scripts

The following scripts have been added to `package.json`:

| Script | Command | Description |
|--------|---------|-------------|
| `cap:sync` | `capacitor sync` | Sync web assets and plugins to native projects |
| `cap:copy` | `capacitor copy` | Copy web assets to native projects |
| `cap:ios` | `capacitor open ios` | Open the iOS project in Xcode |
| `cap:android` | `capacitor open android` | Open the Android project in Android Studio |

## Building for Mobile

1. **Build the web app first:**
   ```bash
   pnpm run build
   ```

2. **Sync web assets to native projects:**
   ```bash
   pnpm run cap:sync
   ```

3. **Open and build the native project:**

   - **iOS:**
     ```bash
     pnpm run cap:ios
     ```
     Then build and run from Xcode.

   - **Android:**
     ```bash
     pnpm run cap:android
     ```
     Then build and run from Android Studio.

## Native Plugin Integration

The app integrates the following Capacitor plugins in `src/main.tsx`:

- **StatusBar**: Sets style to `DARK` and background color to `#0f172a` on app load.
- **SplashScreen**: Hides the native splash screen after the web app initializes.

All native plugin calls are wrapped in `try/catch` so the app continues to work normally when accessed in a standard web browser.

## Rebuilding After Web Changes

Whenever you make changes to the web app:

```bash
pnpm run build
pnpm run cap:sync
```

Then rebuild in Xcode or Android Studio.

## Notes

- The web app remains fully functional as a PWA in browsers.
- The `ios/` and `android/` directories are generated by Capacitor and should not be manually edited for web code changes; use `cap:sync` instead.
- CocoaPods is required for iOS builds. If `pod install` fails, ensure CocoaPods is installed (`sudo gem install cocoapods`).
